# 数据清单与隐私边界（DATA-INVENTORY）

> 面向外部家庭提供服务（ROADMAP P3）之前，这份清单必须成立。
> 它回答六个问题：**采集什么 / 为什么需要 / 存在哪 / 谁能访问 / 保留多久 / 如何删除**。
>
> ⚠️ 本文是**工程能力清单，不是法律意见**。正式对外收费前，应就《个人信息保护法》
> 及儿童个人信息相关规定取得专业意见（见 ADR-005 末节）。

## 0. 总原则

| 原则 | 落实方式 |
|---|---|
| 最小必要 | 只采集支撑产品功能所必需的数据 |
| 家庭隔离 | 所有孩子数据带 `family_id`；跨家庭访问一律 **404**（不泄露存在性） |
| 代码同步，数据与凭据永不同步 | 部署排除 `*.db` / `media/` / `.env` / `.venv`（ADR-003） |
| 可删除 | 每条录音可即时删除；保留期自动清理；账号级删除形状已定 |
| 可导出 | 录音可打包导出（`GET /api/v1/children/{id}/recordings/export`） |
| 凭据不入库 | 门禁口令（哈希+盐）、JWT 密钥、讯飞凭据：不入 git、不进日志、权限 600 |

## 1. progress（学习进度）

| 项 | 内容 |
|---|---|
| 采集 | 课程星级、完成状态、单词掌握、今日时长/玩法数、每日快照 |
| 为什么 | 进度同步与展示；跨设备一致 |
| 存储 | SQLite `progress` 表（`data_json` 文档模型）+ 客户端 localStorage |
| 访问 | 本家庭 JWT；跨家庭 404 |
| 保留 | 长期（学习历史，无期限） |
| 删除 | 随孩子档案删除（形状已定，见 §5） |

## 2. rewards（奖励）

| 项 | 内容 |
|---|---|
| 采集 | 贝壳数、英雄形态、星级 |
| 为什么 | 激励机制 |
| 存储 | SQLite `rewards` 表 + localStorage |
| 访问 / 保留 / 删除 | 同 progress |

## 3. recordings（孩子发音录音）—— **最敏感**

| 项 | 内容 |
|---|---|
| 采集 | 发音音频（webm/wav/ogg/m4a，**≤5MB/条**）、对应文本、时长、评测分 |
| 为什么 | 回听成长 + "越读越准"的分数趋势 |
| 存储 | 音频 `backend/media/<child_id>/`；元数据 SQLite `recordings`（存**相对路径**） |
| 访问 | 仅本家庭；nginx 禁止直出 media，回放必须过 JWT |
| 配额 | 单孩子 ≤200 条 / ≤200MB（超限 429） |
| 保留 | 音频 **90 天**（可配置）；**分数与文本长期保留** |
| 删除 | `DELETE /api/v1/children/{id}/recordings/{rid}` 即时删除；保留期由每日 cron 清理 |
| ⚠️ 必须如实告知 | 14 天滚动备份窗口内，被删音频仍存在于历史快照中 —— **不能声称"删除后立即不可恢复"** |

> "删音频、留分数"是有意为之（ADR-005）：家长要的是趋势，不是三个月前听不清的 webm。
> 音频可重录（可再生），分数不可再生。这让隐私最小化与家长价值同时成立。

## 4. events（埋点事件）

| 项 | 内容 |
|---|---|
| 采集 | 会话 / 进课 / 完成玩法 / 关卡通过 / 磨耳朵 / 前端错误（**不含**录音内容、姓名、对话文本、位置） |
| 为什么 | 北极星（每周主动学习分钟数）+ 线上故障可见 |
| 存储 | SQLite `events` + `daily_stats` 汇总；客户端离线队列 localStorage |
| 访问 | 本家庭 JWT；事件接口单独限流（60 次/分/IP） |
| 保留 | 原始事件 **180 天**；`daily_stats` 汇总长期保留 |
| 删除 | 随孩子档案删除（形状已定） |

口径定义见 `PROGRESS-DATA.md §7`。

## 5. 明确不采集

- 精确地理位置、通讯录、设备唯一标识（IMEI / 广告 ID）
- 孩子真实姓名以外的身份信息
- 对话文本、录音内容用于分析（录音仅用于回听与评测）
- 家长凭据（口令明文、JWT 密钥、讯飞 key）

## 6. 账号级删除（形状已定，未实现）

开放注册（P3）的前置条件。实现时必须：

1. **软删除优先**（先标记 `deleted_at`，延迟真删），避免误操作不可逆；
2. 覆盖四类数据：`recordings`（含 `media/` 文件）、`progress`、`rewards`、`events`；
3. `DELETE /api/v1/children/{child_id}` —— 删孩子档案及其全部数据，需二次确认；
4. `DELETE /api/v1/auth/me` —— 删家庭账号及其全部关联数据。

## 7. 变更记录

新增数据集、改变保留期或采集范围时，**必须同步更新本文 + ADR-005**，
并在 `STABILITY.md §3` 反映对备份体积的影响。
