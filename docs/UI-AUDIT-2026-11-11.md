# UI 全面走查清单（2026-11-11/12）

> 方法：两层走查——layout-audit 全视口矩阵（321-322/322）+ 内置浏览器逐玩法实玩
> （iPad 横屏 1024×768 主视口全 9 玩法走通，phone14 竖屏 390×844 与 SE 横屏 667×375
> 复走关键页）。样本课：l13 晚安大猩猩（新数据）+ l12 安静书 + l4/l5。
> 对象是 5 岁孩子：一屏装下、大触控、少文字依赖、误触有兜底。

## P1（交互缺陷，修）

1. **玩法中途退出无确认**（OrderView/QuizView/SpeakView/TalkView/SpinnerView 等 isClose 关闭按钮）
   — 实测 quiz 第 1/8 题时点左上 X 直接退出、进度全丢。孩子经常误触左上角。
   修：本关已有进度（answered>0 或 timer>10s）时弹孩子化确认「还没玩完哦，真的要离开吗？」（继续玩 / 离开）。
2. **词图缺加载占位**（QuizView/MatchView/TalkView/SpinnerView 首屏）
   — 实测四处首帧图卡空白（图片解码完成前无占位），弱网真机孩子看到的是"一片空卡"。
   修：图容器给统一背景占位（--media-bg 渐变已有，卡片上缺），img 加 decoding=async + 容器固定宽高比。
3. **宝箱锁定态点击零反馈**（关卡列表底部）
   — 可点但不 disabled、点击无任何提示，孩子觉得"坏掉了"。
   修：点击时弹孩子化提示「再玩 X 个玩法就能开宝箱啦」（复用 AppDialog/浮动横幅）。
4. **连一连默认「看词」模式**（MatchView mode 默认值）
   — 左侧纯英文文字卡，5 岁不识字无法独立完成；「听音」模式才是低幼正确形态。
   修：非 l11 颜色课的默认模式从看词改为听音（看词保留为切换项）。
5. **听音模式左侧卡仍印单词**（MatchView listen 模式词卡带 en 文本）
   — 听发音连线被文字提示架空。
   修：听音模式左侧卡只留喇叭图标 + 点击即读，不印 en 文本。

## P2（文字/视觉，修）

6. SongView 文案口径不一：顶部提示「跟着唱完一遍，就能领小星星啦」vs 底部按钮「听完一遍就能领星星」。统一为「听完一遍，就能领小星星啦」（跟唱鼓励但不强制）。
7. 装饰星压进度字：quiz/spinner 左上 `deco-star` 落在「1/8」数字上。给 deco-star 加 pointer-events:none 已有，调位置（避开左上 120×120 信息区）。
8. order SE 横屏 2px 内部溢出（本轮矮横屏压缩档回归）：pic-card 76→74px 或句子条 padding 再收。
9. 竖屏 match 提示文字与模式 tab 挤同一行换行局促：提示条与模式切换分两行（竖屏 media query 下 flex-wrap 或缩文案为「听发音，连对应的图」）。

## P2（观察项，记录不修或低优先）

10. SpeakView 文案「小耳朵打分」「跟读给小耳朵听」含义含糊——"小耳朵"拟人未建立（无吉祥物命名）。待品牌定名后一并拟人化。
11. 桌面端粗黑滚动条（关卡列表/磨耳朵）——加细滚动条样式。
12. 课程列表 iPad 横屏下半屏空旷——卡片可再大一档或垂直居中。
13. QuizView 选项印单词——设计取舍（识词萌芽），保留；听音选图提示语已足够。
14. SongView 领星判定可被拖进度条跳过——低危，孩子主动 seek 也算"接触过"，保留。
15. 各玩法首帧图片空白与 MatchView 空白卡同源（已并入 #2）。
