# 丞丞英语乐园 · 设计规范（Design Guidelines）

> 面向 **5 岁孩子** 的儿童英语学习应用设计总纲。
> 阅读对象：**AI 生成者**（新增/修改页面、组件、交互前先读）、**开发者**、**走查者**。
> 配套文档：[DEVELOPMENT.md](../DEVELOPMENT.md)（架构/响应式/部署）、[README.md](../README.md)（使用）、`src/styles/tokens.css`（视觉 token 唯一事实源）。
>
> **一句话总纲**：多邻国的即时反馈与激励节奏 + 儿童圆体大触控 + 一切可点即发声 + 一屏装下不滚动。

---

## 0. 怎么用这份文档（AI 协作约定）

生成任何新页面、新玩法、新组件或修改交互前，**先对照第 2/5/6/7 章**确认方向，完成后**用第 9 章清单走查**再提交。

- **视觉值一律从 `tokens.css` 取**，禁止在组件里硬编码颜色/字号/圆角/阴影（`--gap-*` / `--fs-*` / `--radius-*` / `--shadow-*` / `--c-*`）。
- **交互状态机先画清楚**（见 §5.1），再写实现；新增状态必须能走完「未作答 → 作答 → 反馈 → 继续」闭环。
- **新增玩法组件放 `src/components/activities/`**，新页面放 `src/views/`，可复用交互沉淀到 `src/components/ui/`。
- **动效/音效/震动**：先查 §7，能复用现有 token 就不新造。
- 改动走 **TDD**：先写/改测试（`src/**/__tests__/`），再实现，`npx vitest run` 全绿才提交。

## 1. 产品定位与用户

| 项 | 定义 |
|---|---|
| 目标用户 | **5 岁左右**的孩子；家长陪同（每次建议 10-15 分钟） |
| 产品形态 | 线下培训班作业补充应用，纯前端、离线可用（PWA） |
| 学习闭环 | 每课一首童谣 → 单词：**看图学词 → 听音选图 → 图词连线 → 跟我读 → 唱童谣 → 亲子对话** |
| 情感基调 | 快乐、被奖励、不惩罚；玩着玩着就学会了 |
| 双模式 | 自由（课程列表）+ 游戏（闯关地图，多邻国式） |
| 家长视角 | 我的 → 家长报告：时长/单词明细/错词清单/进度 |

**设计前提**：孩子认字能力弱 → **图优先、音优先、字为辅**；注意力短 → **每步 10-20 秒、反馈立即出现**；手指精度低 → **目标够大**。

## 2. 设计原则（8 条，违反需在走查中说明）

### P1 一屏装下，永不滚动
- 应用外壳 `#app { height: 100dvh; overflow: hidden }`；页面内容按视口分档布局，装不下的用**分页**（`usePager`）而不是滚动。
- 例外：游戏关卡地图、家长报告这类**需要滚动浏览的信息页**，滚动条贴最边，内容居中文档流。
- 断点分档见 DEVELOPMENT.md §4.3（narrow/wide × tiny/compact/regular/roomy）。

### P2 大目标、大触控
- 可点区域 **≥ 52px**（手机）/ **≥ 64px**（宽屏 `--tap-min`），低于 HIG 的 44px。
- 尺寸全部流体：`clamp(min, min(Avh, Bvw), max)`——只用 vh 或只用 vw 都不对（iPad 横屏/手机横屏会失衡）。
- 面向孩子的按钮/词卡/图卡都要**大而饱满**，宁可少放几个。

### P3 一切可点即发声
- 页面里**所有英文文字**（标题、按钮文字、单词、歌词、介绍文案）点击都应朗读发音。
- 点图/点词卡/点答案条 = 读对应单词；点句子 = 读句子；TTS 不可用时回退提示。
- 朗读时要有**声波动效**（参考宝藏详情页的朗读动效；听音选图顶部喇叭同样带）。

### P4 即时反馈，错不惩罚
- 答对：**立即**绿色反馈（`--state-ok-bg`）+ 彩带（canvas-confetti）+ 星星/连击。
- 答错：**不提示正确答案**，只标红（`--state-bad-bg`）+ 震动 + 异常音效，**标记短暂显示后消失**，让孩子自己再试。
- 选对才进下一题；错误不进入"挫败"体验，始终鼓励重试。

### P5 奖励驱动、循环激励
- 星星（进度）、贝壳（货币）、贴纸/英雄图鉴（收集）、连击（持续性）、开宝箱（阶段奖励）。
- 完成一个关卡/阶段 → 开宝箱（三次点击开箱 + 音效 + 震动 + 抛物线收取到顶部计数）。
- 奖励动画要有"收进"感（参考购物车式抛物线 + 顶部数字跳动接收）。

### P6 儿童圆体、高饱和、立体感
- 字体：`"Baloo 2"`（拉丁）+ `"ZCOOL KuaiLe"` 站酷快乐体（中文）——**圆润、粗、无衬线**。
- 品牌色高饱和（多邻国式），彩色卡片只用 `--c-*` 六个 hue 色调板。
- 卡片/按钮用**立体投影**（`--shadow-hard`：底部实心厚度）+ 圆角 `--radius` + 贴纸白描边 `--sticker`——"可按压的积木"质感。

### P7 简单直接，少字多图
- 孩子看不懂长句：界面文案短（≤ 6-8 字），能用图标/emoji 表达就不写字。
- **功能图标统一用 lucide 图标库**（SVG，`.k-ico`），**禁止用 emoji 符号当功能图标**（emoji 只做内容插画/占位）。
- 层级扁平：主操作一步可达，不设多层菜单。

### P8 暗黑模式随主题、不刺眼
- 由 `src/utils/theme.js` 切 `<html data-theme="dark">`；**开关只在「我的」页**出现，其他页面不展示。
- 暗色原则：品牌色降亮降饱和（防眩光）、卡片面比背景高一档（保层次）、投影补内描边。
- 所有新增样式必须同时提供亮/暗两套，走查时两套都过。

## 3. 视觉规范（事实源：`src/styles/tokens.css`）

### 3.1 颜色
- 中性：`--bg`（米白/深蓝黑）、`--card-bg`、`--ink` 三档文字色、`--line`。
- 品牌：`--green/blue/yellow/red/purple/orange/gold`（按钮、进度条、连线）。
- 卡片色调板：`--c-blue/green/orange/purple/pink/teal` + 对应 `-deep` 投影色，通过 base.css `.tone-*` 工具类使用。
- 状态：`--state-ok-bg`（答对底）、`--state-bad-bg`（答错底）、`--btn-off-*`（禁用灰）。
- **规则**：有颜色的大卡片/按钮必须用色调板，禁止自造色值。

### 3.2 字体与字号
- 全站字体栈已定（Baloo 2 + 快乐体），新增中文文案若超出字体子集，重跑 `scripts/subset-font.py`。
- 字号层级：`--fs-hero/title/body/small/btn/emoji-*`，全部流体；宽屏（≥768px）自动放大一档。

### 3.3 形状与质感
- 圆角 `--radius`（大圆角）、`--radius-pill`（胶囊按钮）；卡片投影 `--shadow-hard`、按压下压 `--press`。
- 背景质感：`CuteBackdrop.vue` 双主题——**水彩**（全站默认，含云朵/星星/圆点装饰）+ **天空草地**（`?mode=game` 地图页，含太阳/山丘/云朵）。背景是内容之下的陪衬层，**不得被页面容器不透明背景盖住**（页面容器用透明）。

### 3.4 图标
- 统一 lucide-vue-next（`.k-ico`，1em 见方，描边 2.6）。
- 底部导航/顶栏/关卡/按钮图标全走图标库；锁用 `Lock`、关闭用 `X`、返回用 `ChevronLeft` 等语义图标。

## 4. 布局与适配（手机 / iPad / Mac 三端）

- **App 形态**：固定顶栏（HeaderBar）+ 内容区 + 常驻底部导航（BottomNav：学习/游戏/我的）；课程内沉浸学习时隐藏底栏。
- **底栏**：半透明毛玻璃（`--bar-bg` + `--bar-blur`），固定底部，点击区域 ≥ 64px，切换即时、无延迟感。
- **顶栏**：返回/关闭 + 标题 + 进度；课程内答题页顶栏 = **关闭按钮 + 顶部进度条**（进度条就一条，不放别处）。
- **信息页滚动**：关卡地图/报告页允许纵向滚动，滚动条贴最右，内容居中；关卡地图关卡标题滚动吸顶。
- **分页**：词卡/选择题一屏装不下的用分页（圆点指示器），不滚动。

## 5. 交互规范（核心：什么时候出现什么、怎么动）

### 5.1 通用状态机（所有玩法/关卡步骤）
```
未作答 ──点选/作答──▶ 已作答 ──检查──▶ 结果反馈 ──继续──▶ 下一步 / 关卡结算
   │                    │                 │
   │（主按钮=灰"检查"）  │（主按钮=绿"检查"）│ 对→彩带+星；错→红标短暂显示+震动，不提示答案
```
- **主按钮常驻底部**（LessonFooter）：未作答=灰色"检查"，已作答=绿色"检查"，检查后可"继续"。
- 错误标记：**显示一下立即消失**，孩子自己发现并重选；选对才推进。

### 5.2 发音交互
- 触发：点击任何英文文字/图片/答案条。
- 反馈：播放语音 + 声波动效（说话者头部旁边或喇叭后方）。
- 失败降级：无 mp3 → TTS；TTS 不可用 → 显示"未上传/无法发音"占位，不报错卡死。

### 5.3 跟我读（SpeakView）
- **按住说话、松手停止并自动回放**录音；**不给孩子看进度条**，回放完直接出现"很棒/不错/再试一次"三档反馈。
- 录音按钮**靠下、大**（方便孩子按到），上方图片/单词更大更突出。
- 双模式：浏览器识别打分 → 失败降级录音回放（家长/老师 👍/🔁 判定）。

### 5.4 答题（Learn/Quiz/Match）
- 答案选项大卡片；点击即发音；选中高亮（`--tint-*`）；检查后对错底色区分。
- 连一连：SVG 连线（Pointer Events 兼容鼠标/触屏），连线画在最上层（`--z-lines`）。
- 听音选图/选词：顶部喇叭带头部声波动效；错选只标错、不显示答案。

### 5.5 关卡与奖励
- **关卡地图**（GamePath）：S 形蜿蜒排列，每单元首尾关卡从屏幕水平居中开始；无连线（参考多邻国），圆卡片 + 外圈**进度圆环**（呼吸动画：小→稍大，无限循环，阴影算进视觉）；未解锁=锁图标（统一 icon）。
- **开宝箱**（ChestReward）：独立步骤。**点宝箱三下打开**——每次点击宝箱抖动 + 下方三个图标依次点亮 + 音效；第三次打开后出现"收取"，宝石/贝壳**抛物线飞向顶部数量统计**，顶部数字跳动接收，收完动画停止。
- **关卡结算**（LessonResult）：独立总结页——显示"完成什么 + 获得几颗星"，**不挤在最后一题**。

### 5.6 导航与反馈
- 答题页顶部：**关闭**（X，图标库）+ 进度条；**不放课程标题、不放暗黑切换**。
- 未解锁关卡点击：**震动 + 异常音效 + 抖动动画**，不弹窗。
- 弹窗/对话框：统一 `ui/AppDialog`；**孩子场景优先用"震动+音效+动画"替代文字弹窗**。
- 底部切换：即时响应，切换失败要可恢复（点击穿透/遮挡是 bug）。

### 5.7 Header（顶栏）规范

顶栏按场景分四类，**信息密度与主操作分工明确，header 不留空**：

| 场景 | 组件 | 左侧 | 中间 | 右侧 |
|---|---|---|---|---|
| 主 Tab（学习/游戏/我的） | `AppHeader` | 标题（图标+文字，**可点发音**） | — | ⭐🐚🔥 全局三徽章（固定不变） |
| 二级页（返回） | `HeaderBar` | 返回按钮 + 标题（**可点发音**） | — | 该页关键信息/操作（日期/计数/状态/放大等） |
| 沉浸任务页（步骤型玩法 learn/quiz/match/speak） | `HeaderBar` | 关闭（✕，弱化） | **顶部进度条**（玩法上报 0-100） | 本课星星 |
| 无进度玩法（song/talk） | `HeaderBar` | 关闭 | 留白（沉浸，不强行填） | 本课星星 |

规则：

1. **标题都可点发音**：主 Tab 标题、二级页标题、课程名点击即朗读。
2. **内容上移原则**：header 右侧/中间为空时，从内容区提取**最关键的信息或操作**上移（例：英雄详情→右上角放大按钮；打卡日历→右上角今日状态徽章），不留空、不堆砌。
3. **进度唯一性**：沉浸任务页的顶部进度条是**唯一进度源**——内容区不再放第二条进度条/重复指示（Pager 圆点可经 `hide-dots` 隐藏）。
4. **返回 vs 关闭**：二级页用返回（← 圆钮），返回目标=上一级（宝藏库/首页/本课菜单）；沉浸任务页用关闭（✕ 弱化），退出=离开本玩法。
5. **童谣（song）用播放器自身进度、亲子对话（talk）自由探索**，不进顶栏进度条。
6. **暗黑/声音开关只在「我的」页**，任何 header 不出现。

## 6. 内容规范（什么时候生成什么文案/资源）

- **英文优先、中文辅助**：标题/单词/歌词英文为主，中文小字释义；**亲子对话英文在上、中文在下**。
- 单词卡片：英文大字（可点发音）+ 中文小字 + 图片/emoji 占位。
- 童谣歌词：结构化时间轴（类 LRC，JSON 含每句起止时间），用于**歌词高亮跟唱**，不改动音频/视频。
- 文案语气：短句、肯定、鼓励（"很棒！""再试一次！"），**无惩罚性表述**。
- 可点文字都发音：底部导航、课程标题、报告标题等英文内容点击即读。
- 资源缺失：图片→emoji 占位；音频→"未上传"占位可点领星；**不因缺资源而断流程**。

## 7. 动效 / 音效 / 震动规范

| 类型 | 触发场景 | 规范 |
|---|---|---|
| 按压反馈 | 点击任何按钮/卡片 | `--dur-fast` 弹缩 + 下压 `--press` |
| 答对 | 检查通过 | 绿色底 + 彩带（canvas-confetti）+ 星星入账，`--ease-pop` |
| 答错 | 检查失败 | 红色底短暂显示 + 震动 + 低音"叮"，`--dur-base`，标记自动消失 |
| 发音 | 点击文字/图片 | 声波动效（说话者旁/喇叭后） |
| 开宝箱 | 宝箱步骤 | 三击开箱：抖动+音效+图标逐一点亮；收取：抛物线 `--dur-fly` + 顶部计数跳动 |
| 进度环 | 关卡地图 | 呼吸缩放（约 4.6s 循环），小=贴紧图标、大=略大一圈 |
| 减少动效 | 用户偏好 | `prefers-reduced-motion` 关闭动画 |
| 触感 | iOS | 玩法反馈可震动；导航类按钮 iOS 不震（安卓正常） |

**音效**：Web Audio 合成（零资源），覆盖点击/对/错/开箱/收取；音量随全局声音开关（「我的」页）。

## 10. 扩展迭代原则

1. **新玩法** = 新的 `activities/*View.vue` + 复用 §5.1 状态机 + `LessonFooter` + 反馈规范；数据进 `src/data/lessons.js`（课时结构）或新增 store（进度/奖励）。

3. **新视觉** = 先补 `tokens.css`（禁止组件里造新值）→ 再实现 → 亮暗两套。
4. **新动效** = 先查 §7 能否复用（时长/缓动/音效），不复用才新增并登记。
5. **复杂度上升**：状态跨页面共享 → 提 store；深链/分享需求 → 玩法提为独立路由（现状玩法内 stage 由 LessonView 管理，保持低耦合）。
6. **每次迭代**：先补测试（TDD）→ 实现 → 三端走查 → 提交。
