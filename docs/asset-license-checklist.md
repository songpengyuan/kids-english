# 素材授权确认清单（收费前必须逐项落实）

> 目的：把"老师/外部提供的素材"从**人情授权**升级为**书面授权**。
> 自用（自家孩子学习）不需要这份清单；**对外分发/收费前**必须逐项确认。
> 最后更新：2026-11-08

## 背景

课程的传统儿歌（旋律/歌词进入公版领域，**词曲本身无版权问题**），但
"老师演唱/演奏的录音"是老师的**表演者权**（录音制品制作者权），分发前
需要老师书面同意。绘本扫描件类素材（已替换，见下文"已处理"）属于
出版社/作者的复制权，任何人都无法代为授权——已全部清除。

## 授权书要点（找老师签时需要覆盖）

1. **授权内容**：明确列出哪些录音文件（按课列出文件名即可）
2. **授权范围**：在"××产品"（写产品最终定名）中**全球范围、非独家、免费**使用，
   包括随产品分发/缓存/在线播放
3. **转授权**：允许为产品运营需要做格式转换/压缩等技术处理（不改内容）
4. **期限**：永久或长期（避免每次更新都要重签）
5. **署名**：是否愿意在"关于"页署名（老师通常乐意，也是对产品的背书）
6. **签字 + 日期**：纸质或微信书面确认均可（聊天记录+文件名列表也有效力，
   但正式一点更稳）

## 已替换素材的存档说明

  若未来转公开仓库需要 `git filter-repo` 清历史（与录音出仓同一批处理）。
- 删除后如老师/家长想留底，原始文件在家庭电脑的备份里（不在仓库）。

## 换新内容的检查习惯

以后每接一批老师素材（新音频/图片/视频），入库前先问一句：
"这个素材是我做的、老师给的（可签授权）、还是网上找的（不可入库）？"
——网上找的素材一律不入库，用生成管线重做。
