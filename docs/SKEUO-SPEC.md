# 拟物化（Skeuomorphism）视觉规范

> 目的：把底部 tab 那套「3D 实体感」从一次性设计变成可复用、可验收的规则，
> 避免后续每个组件自己写阴影值、自己调厚度，最后拼成两套风格。
>
> 前端是给孩子用的：**拟物的意义不是炫技，是把「符号」变成「孩子认识的实物」**。
> 一个 3D 的小话筒比一个线条话筒更容易被 5 岁孩子认出来「这是要说的话」。
> 因此任何拟物改造都要先问：这个元素是不是孩子会用手去摸/点的实物？

## 一、三层级

| 层级 | 定义 | 典型元素 | 必备视觉 |
|---|---|---|---|
| **L1 图标** | 贴纸/小物件，不可单独点击 | 底部 tab 图标、玩法图标、入口小图标 | 拟物图片（webp）+ 悬浮投影，**无厚度** |
| **L2 按键** | 可以被点/按下 | 关卡节点、主按钮、徽章胶囊 | 顶面 + 下方**实心底座** + 落地投影；按下压到 ~1px |
| **L3 容器** | 承载内容的实体 | 宝箱、卡片托板、底部 tab 托板 | 内阴影高光（顶面受光）+ 底部实心边 |

**判断口诀**：能按下去的是 L2，装着东西的是 L3，只是「贴在面上的一张贴纸」的是 L1。

## 二、Token（`src/styles/tokens.css`）

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--sk-depth` | `7px` | 同 | L2 默认厚度（68px 级按键） |
| `--sk-depth-sm` | `3px` | 同 | L2 小尺寸（徽章/小胶囊）——7px 会把 28px 高的胶囊撑胖 |
| `--sk-depth-lg` | `clamp(6px,1.2vh,10px)` | 同 | 大按键 / 容器 |
| `--sk-base` | `rgba(0,0,0,.22)` | `rgba(0,0,0,.55)` | 底座（实心侧壁）色 |
| `--sk-shadow` | `0 5px 14px rgba(0,0,0,.12)` | `0 5px 14px rgba(0,0,0,.35)` | 落地投影（模糊） |
| `--sk-gloss` | 白 0.5→0（55% 收干） | 白 0.16→0 | 顶面高光叠加层 |
| `--sk-press-scale` | `0.97` | 同 | 按下缩放 |

### 用 `--sk-gloss` 的两种合法写法

```css
/* A. 面是纯色：高光层 + 颜色层 */
background: var(--sk-gloss), var(--face);

/* B. 面本身就是渐变：高光层 + 渐变层（不要给渐变面再写 inset 高光，会双重受光） */
background: var(--sk-gloss), linear-gradient(180deg, var(--tone), var(--tone-deep));
```

`background: <image>, <color>` 与 `background: <image>, <image>` 都合法，
所以同一个 `--face` 变量既能放纯色也能放渐变，组件不用关心当前是哪种态。
这是关卡节点三态（done 课程色渐变 / active 金黄 / locked 灰）共用一束光的原因。

### 底座与投影必须同时存在

```css
/* L2 标准写法 */
.sk-button {
  background: var(--face);                       /* 顶面：纯色或渐变 */
  border-radius: 50% / 而椭圆用 50% + 宽度>高度;
  box-shadow:
    0 var(--sk-depth) 0 var(--sk-base),          /* ① 实心底座 = 侧壁厚度 */
    0 calc(var(--sk-depth) + 5px) 14px var(--sk-shadow-shadow-color); /* ② 落地投影 */
}
.sk-button:active {
  --sk-depth: 1px;                               /* 厚度塌下去 */
  transform: translateY(5px) scale(var(--sk-press-scale));
}
```

- 只写投影不写底座 → 看着像「贴纸浮在纸上」，没有体积。
- 只写底座不写投影 → 像「立在空中」，没有落地的重量。
- 高光（`--sk-gloss`）叠在**顶面之上**（用 `background-image` 多层，或 L3 的 `inset` 高光），
  不要单独用一个半透明遮罩层，否则会盖住内容图标。

## 三、几何约定

- **椭圆而非正圆**：俯视透视的圆柱体，横向略宽、纵向略扁。关卡节点用 `68×57`（≈1.19:1）。
- **圆角**：L2 按键 `border-radius: 50%`（椭圆靠宽高比实现）；L3 容器上圆角小、下圆角大
  （`12px 12px 4px 4px` 的盖 vs `6px 6px 16px 16px` 的箱体），模拟「上沿薄、下沿厚」。
- **高光位置**：统一从顶面顶端往下 55% 收干。方向一律自上而下，全站不出现斜向光源。

## 四、动效约定

| 场景 | 曲线 | 备注 |
|---|---|---|
| 按下 | `var(--dur-fast)` + `translateY` 到厚度塌陷 | 按压必须「看得见」，12ms 级 |
| 弹入 | `var(--ease-pop)` = `cubic-bezier(.34,1.56,.64,1)` | 落地有回弹 |
| 开盖/弹出 | `cubic-bezier(.34,1.4,.64,1)` | 过冲幅度小于 `--ease-pop` |

拟物动效的红线：**不要给静态元素加无意义的循环动画**。待机呼吸（如宝箱 `chest-idle`）
幅度必须小到「不盯着看注意不到」，它是呼吸感不是求关注。

## 五、暗色主题

必须同时调，不能只改亮色：

- 底座从 0.22 提到 0.55（深底上黑色半透明等于没有）。
- 高光从 0.5 降到 0.16（强了会在深色面上糊成灰雾）。
- 落地投影提高到 0.35。
- 已着色顶面（如课程主题色渐变）在暗色下要跟深底混合：
  `color-mix(in srgb, var(--tone) 62%, var(--black))`，不然亮色顶面会「发光」得刺眼。

## 六、图标素材（L1）

- 位置：`frontend/public/nav/` 与后续新增的拟物图标目录。
- 格式：**webp**（带 alpha），自托管，不引 CDN。
- 风格锚点：现有 `learn.webp` / `listen.webp` / `me.webp` 三张。新图标必须以它们为参考生成，
  保证**同光源方向（顶光）、同圆角语言、同投影角度**，否则一眼看出是两套图。
- 尺寸档：`sm 28px` / `md 40px` / `lg 52px`，统一走 `SkIcon.vue`。
- 未选中态沿用底部 tab 的处理：`opacity: .7` + `saturate(.82)` + `scale(.92)`。
- **`continue`（继续学习）不用拟物图**：那一行是 primary 实体按钮（L2），
  往里再叠一个 L1 实物会削弱「这一整条是可以按下去的按钮」的观感。
  L2 内部统一用 `IconTile`（半透明白托盘 + lucide 线条图标）——这一条是判定规则，
  后续新增 primary 入口时同样不要塞拟物图。

### 素材过来必须验两件事（血泪）

模型生成的「透明底」**不一定真透明**，而且肉眼在深色页面上看不出差别，只在浅色卡上变成白方块。

1. **验 alpha**：`np.unique(arr[:,:,3])` 只有 `[255]` 就是假透明（浅灰白底 `(231,231,225)` 也算）。
2. **验渲染**：把图丢进 `public/nav/`，用 Chrome 打开一张 `background:#1a5` 的测试页，
   **看到绿色透出来才算通过**。`PIL` 读着透明 ≠ 浏览器渲染透明。

假透明的补救：`ImageDraw.floodfill(tmp, 四角, (255,0,255), thresh=45)`
→ 按品红标记生成 alpha → `GaussianBlur(1.2)` → `alpha[alpha<60]=0`
→ 按 `alpha>100` 取 bbox 裁切 → 8% 留白补方形 → `resize(512,512, LANCZOS)`。

- 阈值必须 **≥40**。`thresh=16` 填不动浅灰底（背景与主体边缘色差可达 20+）。
- **饱和色主体（橙环、蓝日历）安全**；**奶白/浅色主体 + 浅色底则抠不干净**
  （主体与背景色差仅 15–20，抠掉背景的同时会啃掉主体边缘）——这种图只能重生成成饱和色版本。

## 七、验收清单

改完任何拟物元素都要过：

- [ ] 亮色 / 暗色双主题截图对比同一页
- [ ] `node scripts/layout-audit.mjs`（手机 / 平板 / 桌面三端）
- [ ] `npm run test` + `node scripts/validate-data.mjs`
- [ ] 新增 webp 总体积 < 300KB
- [ ] 图标 `aria-hidden` / 可点元素有 `aria-label`
- [ ] 按压态在真机上「看得见」（不是只有 0.x 的 scale 变化）

## 八、明确不做拟物的区域

信息密集、受众是大人的界面不拟物化——拟物会让它变重、变慢：

- 家长中心内的表单、按钮组
- 学习报告的图表与数据表
- 磨耳朵歌单长列表（一屏七八行，拟物会挤成一堵墙）
